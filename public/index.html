    통계 기록·수정 안내

    화면에서 인식한 조각은 실제 배치를 반영한 뒤 한 번씩 기록합니다. 수동 선택은 첫 추천·직접 배치 때, 수동 바꾸기 입력은 결과 반영 때 기록합니다. 예시 화면은 제외하며, 되돌리면 통계도 복구됩니다.

    비율 = 해당 블록 횟수 ÷ 해당 열 전체 횟수. 누적 관측 비율이며 실제 확률을 보장하지 않습니다. 화면에서 이름을 구분할 수 없는 모양은 미분류로 집계합니다.

    일반·바꾸기 누적 횟수를 표에서 직접 고친 뒤 Enter를 누르거나 다른 칸으로 이동하면 저장합니다. 편집을 마치면 정렬이 갱신되며, 검색해도 비율은 선택한 범위의 전체 기록 기준입니다.

    단계별 횟수 수정은 전체 합계에도 반영됩니다. 전체 횟수는 단계별 합계보다 작게 줄일 수 없습니다. 기존 기록은 단계 미상으로 보존합니다.
